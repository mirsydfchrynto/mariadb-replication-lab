LANGKAH PENGUMPULAN TUGAS OLEH SUBHAN YOGA MAULANA (3 LANGKAH MUDAH):
--------------------------------------------------------------------------------
Langkah 1: Isi Suara Asli (Dubbing)
- Buka video di folder `01_VIDEO_DOKUMENTER` menggunakan CapCut / Premiere / HP.
- Rekam suara Subhan membaca kalimat pada file `02_NASKAH_BACAAN` sesuai menit [MM:SS].
- (Opsional tetapi sangat bagus): Tempelkan rekaman webcam wajah Subhan di sudut
  layar saat menit 00:00 (perkenalan) dan menit 12:40 (penutup).
- Export video hasil gabungannya.

Langkah 2: Upload Video ke YouTube
- Buka https://youtube.com -> Login akun Subhan -> Klik Buat (+) -> Upload Video.
- Beri Judul: Tugas 3 Praktik Basis Data MSIM4206 - Subhan Yoga Maulana - 044876223
- Pilih Visibilitas: "Tidak Publik" (Unlisted) atau "Publik" (Public).
- Salin (Copy) link video YouTube tersebut.

Langkah 3: Tempel Link ke Laporan Word & Kirim ke e-Learning UT
- Buka file `03_LAPORAN_PRAKTIKUM_FINAL\TUGAS_3_SUBHAN YOGA MAULANA_044876223.docx`.
- Pada Halaman 1, tempelkan link YouTube tadi ke dalam kotak tabel "Link Youtube".
- Simpan (Ctrl+S) atau Save as PDF, lalu upload file laporan tersebut ke e-Learning UT.
